[h1]Round Report[/h1]
See what your crew accomplished at the end of each multiplayer round.

English is the primary language of this Workshop page. The mod automatically localizes its interface for each player.

Round Report tracks repairs, welding, healing and CPR, firefighting, enemy damage, kills, deaths, friendly fire, hull damage and reactor incidents. The expedition debrief highlights the MVP, crew contributions, commendations and incidents.

[h2]Features[/h2]
[list]
[*]Current-round and server-session totals.
[*]Native Barotrauma-style report window with job icons and contribution bars.
[*]Hover over scores to see the MVP rules and penalties.
[*]Chat reports for players without the client-side LuaCs patch.
[*]Player statistics survive renames and authenticated reconnects while the server runs.
[*]Automatic language selection: all 13 game languages plus Ukrainian. Unknown languages fall back to English.
[/list]

[h2]Requirements and setup[/h2]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=2559634234]Lua For Barotrauma[/url] is required. Enable Lua For Barotrauma and Round Report on the multiplayer host.

For the report window, players also need the client-side LuaCs installation described on the Lua For Barotrauma page. Subscribing to Round Report alone does not install that client patch. Players without the patch receive chat reports instead.

[h2]Commands[/h2]
[list]
[*]!stats — this round's crew report.
[*]!mystats — your own statistics for this round.
[*]!total — totals since the server started.
[/list]

[h2]Languages[/h2]
English, Ukrainian, German, French, Polish, Russian, Brazilian Portuguese, Castilian Spanish, Latin American Spanish, Turkish, Japanese, Korean, Simplified Chinese and Traditional Chinese.

The window follows each player's game language. Server-generated chat follows the server language. Reload Lua after changing the game language.

[h2]Scope and status[/h2]
Multiplayer only. Statistics are kept in memory and reset when the server restarts. MVP scores are recalculated for the selected period, not summed across rounds.

Version 0.4.0 targets Barotrauma 1.13.4.0. The current build has been manually verified in-game through a complete multiplayer round and passes 27 automated tests.

The preview is an illustrative render with demonstration data, not an in-game screenshot.
