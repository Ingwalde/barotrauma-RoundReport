[h1]Round Report — Multiplayer Expedition Debrief[/h1]

[i]Find out who kept the submarine alive — and who nearly sank it.[/i]

Round Report turns the end of every multiplayer round into a proper expedition debrief. It tracks each crewmember's contribution, presents the results in a Barotrauma-inspired interface, and selects the round MVP using transparent, configurable scoring rules.

The interface automatically follows each player's game language. Players without the client-side LuaCs patch still receive the report in chat.

[h2]What it tracks[/h2]
[list]
[*]Electrical and mechanical repairs
[*]Welding and hull maintenance
[*]Healing and CPR
[*]Firefighting
[*]Damage dealt and enemies killed
[*]Deaths and friendly fire
[*]Hull damage and reactor incidents
[/list]

[h2]Expedition debrief[/h2]
At the end of a round, the crew receives a clear summary with:
[list]
[*]The round MVP and their final score
[*]Crew contribution bars and job icons
[*]Team totals for every tracked category
[*]Commendations for category leaders
[*]Incident highlights for deaths, friendly fire and reactor failures
[*]Separate tabs for the current round and campaign totals
[*]Score tooltips explaining exactly how MVP points were calculated
[/list]

[h2]Persistent campaign statistics[/h2]
Campaign totals survive server restarts and are stored separately for every campaign save. Switching campaigns automatically switches to that save's own statistics.

The data is written locally beside the campaign save, with a backup copy for recovery. Current-round statistics always start fresh after a server restart.

[h2]Configurable scoring[/h2]
Server owners can adjust the importance of repairs, welding, healing, firefighting, damage and kills. Death and friendly-fire penalties can also be changed, and reactor meltdowns can optionally disqualify a player from MVP.

The host's active rules are synchronized to every report window, so displayed scores and tooltips always match the server configuration.

[h2]Commands[/h2]
[list]
[*][b]!stats[/b] — show the current round's crew report
[*][b]!mystats[/b] — show your personal statistics for this round
[*][b]!total[/b] — show saved totals for the current campaign
[*][b]!rrversion[/b] — show the mod version and persistence diagnostics
[/list]

[h2]Languages[/h2]
English, Ukrainian, German, French, Polish, Russian, Brazilian Portuguese, Castilian Spanish, Latin American Spanish, Turkish, Japanese, Korean, Simplified Chinese and Traditional Chinese.

The report window follows each player's selected game language. Server-generated chat follows the server language. New or unsupported game languages automatically fall back to English.

[h2]Requirements[/h2]
[list]
[*]Multiplayer only
[*]Barotrauma 1.13.4.0
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=2559634234]Lua For Barotrauma[/url] enabled on the host
[/list]

To use the graphical report window, players need the client-side LuaCs installation described on the Lua For Barotrauma page. Installing Round Report by itself does not install that patch. Players without it remain fully supported through chat reports.
